🌹 Editor dos 15 Terços

Edite as mensagens, veja como ficam e gere as etiquetas com QR Code.

Como publicar as alterações: suas edições ficam salvas neste navegador (rascunho). Quando terminar, clique em Baixar messages.js e substitua esse arquivo no repositório do GitHub. Depois de alguns instantes, o site já mostra os novos textos — os QR Codes continuam os mesmos.
É o endereço do GitHub Pages. Cada QR Code leva a esse endereço + ?id=número. Se você mudar este endereço, os QR Codes mudam — defina antes de imprimir.
